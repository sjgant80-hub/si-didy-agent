## RULE 1 · Fiverr auto-prepends "I will "

**Fiverr auto-prepends "I will " to every gig title at render time.**
So your submitted title field must NOT start with "I will".
If you type "I will build X" · buyers see "I will I will build X" ·
Fiverr rejects with: "Title can not contain 'I will' or 'for $5'."

  · Titles below in this brief have "I will" stripped already.
  · Titles also cannot begin with "!" nor contain "for $5".
  · Max 80 chars applies to the STRIPPED title, not the "I will …" form.

## RULE 2 · Sequence · finish title BEFORE touching category

Category is a dropdown that can OVERLAY the title field when open.
Clicks/keystrokes leak between them if you interleave. Do this order:

  a) Fill title (browser_fill preferred · never Ctrl+A on Fiverr)
  b) browser_screenshot · CONFIRM title reads correctly (no "I will I will")
  c) browser_click on empty background AWAY from title AND category
     (e.g. on the "Gig title" label text · click x,y around 250,441)
  d) browser_screenshot · confirm focus is off title, no dropdown open
  e) ONLY NOW open category dropdown

## RULE 3 · Field-clear (only if a field has stale text)

  · PREFER browser_fill with a selector (React-controlled inputs respond
    to browser_fill because it uses the DOM value setter + input event).
  · If browser_fill fails · click → End → Shift+Home → Delete → type.
  · NEVER retype without a verified clear.
  · NEVER Ctrl+A on Fiverr fields.

## RULE 4 · Trust Fiverr's error over your screenshot

If Fiverr's Save button returns a validation error · that error is TRUTH.
The screenshot render can be misleading (overlays, tooltips, dropdown
positioning). Read the error, fix the specific field it names, retry.
