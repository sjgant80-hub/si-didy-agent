POST 3 · FOR BUILDERS (the architecture · day 8)
────────────────────────────────────────────────────────
audience: developers · open-source supporters · privacy-tech crowd
hook: the architecture choices · what sovereign single-file looks like
pinned comment: source code link · CLAUDE.md philosophy

▼ COPY ▼
The technical architecture of GroundLevel · for builders who want to see how a sovereign legal tool can be built.

One HTML file. 187KB. 4717 lines. Vanilla JS.

Why:

· no backend means nothing to subpoena. The bailiff cannot serve papers on a server that does not exist.
· no account means no honeypot. There is no user database to breach.
· no CDN dependency in the core shell means the tool works when the platform you're suing is your internet provider.
· no framework means the file is auditable in a weekend. Read it. Verify it. Fork it.

Three things make it different from any "AI lawyer" product on the market:

1. Storage is IndexedDB in YOUR browser. The case file never traverses a network. There is no privacy policy because there is no data collection.

2. The evidence vault uses SHA-256 prevHash chaining. Every captured item links to the previous via cryptographic hash. Tamper-evident by construction. Same standard digital forensics uses for chain of custody.

3. EU AI Act Article 12 audit shim is baked in. Drop-in script tag from fall-euaiact CDN. Every interaction creates a logged event. Regulator walks in, you open DevTools, you show them the chain.

What it does NOT have:

· no LLM API calls at runtime. The templates are static text with variable substitution. No inference cost. No model dependency. T0 always works.
· no analytics. No telemetry. No "anonymous usage data."
· no premium tier. No "Pro" features held back. The whole tool is free.

What it has at its core:

· 60 templates. Every one cites a real Act, real section, real CPR rule.
· 12 module flows. Each walks you through evidence → letter → regulator → court → enforcement.
· Plain-English explanation for every legal concept. Before the jargon. Always.

MIT licence. Fork it. Self-host it. White-label it for your bar association if you want — just keep the philosophy in the LICENCE: this is for the people not the few.
