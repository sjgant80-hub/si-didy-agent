If your AI system outputs anything to an EU user, you owe them an Annex IV.

Yes, even your "low-risk" SaaS using an LLM API thinks they're exempt. The Act disagrees · "minimal risk" still requires the 14-field technical documentation under Article 11. Deadline: August 2026. Eight weeks.

import { createAnnexIV } from 'fall-euaiact';

const doc = await createAnnexIV({
  systemName: 'YourSaaS',
  intendedPurpose: 'Customer support automation',
  riskTier: 'minimal',
  providerName: 'YourCompany Ltd',
  euRepresentative: '...',  // 10 more fields prompted
});

// PDF · markdown · JSON envelope · 24 official EU languages
await doc.export({ format: 'pdf', language: 'en' });
await doc.export({ format: 'pdf', language: 'de' });

// signed against the same audit chain as your Article 12 logs
const signature = await doc.sign(yourEd25519Key);

▼ COMMENT ▼

The Annex IV 14 fields, for the curious (Article 11 Annex IV):

1. General description of the AI system
2. Detailed description of elements and development process
3. Detailed information about monitoring, functioning and control
4. Risk management system (Article 9)
5. Modifications to the system through its lifecycle
6. Listing of harmonised standards applied
7. Copy of the EU declaration of conformity
8. Detailed description of the post-market monitoring system
9. The performance metrics (accuracy, robustness, cybersecurity)
10. Data sheets describing training methodologies
11. The technique used for evaluating the system
12. Cybersecurity measures
13. Information about the system's compliance with this Regulation
14. The intended purpose and risks

Each gets a field in the SDK. Fill what applies · null what doesn't · the doc auto-references which articles each field maps to.

If you're missing fields 9-11 (performance metrics, data sheets, evaluation), that's the actual compliance gap most teams have. The audit-shim from last week handles field 8 (post-market monitoring) automatically once installed.
