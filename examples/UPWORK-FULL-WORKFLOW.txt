THE WORKFLOW
═══════════════════════════════════════════════════════════════════

STEP 0 · AUTH CHECK
  T3 · browser_navigate to https://www.upwork.com/nx/find-work/
  browser_screenshot.
  If a login screen is visible:
    ask_user "Please log in to Upwork in the open browser, then say
              'go' when you see the Find Work page."
    Wait for "go". Re-screenshot to confirm.
  If logged in: continue silently.

STEP 1 · PROFILE REPOSITIONING (skip if already done · ask first)
  ask_user "Has the profile already been repositioned with the v1.2
            elite content? [yes/skip/no]"

  If "yes" or "skip": jump to STEP 2.
  If "no":
    1.1 browser_navigate to my profile URL.
    1.2 Find and click the pencil/edit icon next to the HEADLINE.
    1.3 Select all (Control+a) · browser_type the verbatim headline.
    1.4 ask_user "Save the new headline? [yes/no]"
    1.5 On yes: browser_click Save · screenshot to confirm.
    1.6 Repeat for: Overview/Bio · Hourly Rate · Categories · Skills
    1.7 After each save: screenshot + brief ack to me.
    1.8 If a field doesn't exist or layout differs: screenshot,
        ask_user how to handle.

STEP 2 · PULL FRESH JOBS (Tier 1 if RSS available · else Tier 3)
  Try T1 first:
    Upwork RSS feeds exist for saved searches.
    ask_user "Paste your saved-search RSS URL (Upwork → Find Work
              → My Saved Searches → RSS icon)."
    Once provided · http_fetch the URL · parse · get last 20 items.

  Fallback T3 if no RSS:
    browser_navigate to https://www.upwork.com/nx/search/jobs/?
                       sort=recency&q=AI+app
    Scrape job cards · titles + URLs + budget snippets.

STEP 3 · TRIAGE EACH JOB
  For each job · run the TRIAGE FILTER:
    SKIP if:
      · Hourly cap below $80 (we won't compete on price)
      · Fixed budget below $1,500
      · Requires team of 5+ (we're single-author)
      · "Looking for cheapest" or "low budget" in description
      · Wordpress · Shopify theme · pure design · pure SEO copywriting
      · 50+ proposals already (too noisy)
      · Client has 0 hires + 0 reviews (unscored)

    PROCEED if:
      · AI / LLM / agent / automation in the title or description
      · Custom build (not template / theme / plugin)
      · Single-file / sovereign / self-hosted / no-cloud is mentioned
        OR matches the sovereign positioning naturally
      · Hourly $80-$300 OR fixed $2,500+
      · Client has 1+ verified hire and $5K+ spent
      · "Long-term" / "ongoing" / "retainer" boost score

  Log each triage decision (skip/proceed + 1-line reason).

STEP 4 · DRAFT PROPOSAL (use the COPY GATE frame)
  For each PROCEED job · generate a proposal using these 6 layers:

  LAYER 1 · JUNG (archetypal voice + shadow surfacing)
    Open by naming what they actually want — not what they wrote.
    "You probably don't want another AI agency · you want something
     that works without their meter running."

  LAYER 2 · FREUD (puncture the rationalised want)
    Name the gap between ego ("we need a chatbot") and id ("we want
    to stop paying $4k/mo to OpenAI · we want to own our pipeline").

  LAYER 3 · SALES 101 (hook · stakes · specificity · proof)
    Hook: one line they didn't expect.
    Stakes: what continues to cost them if they hire generic.
    Specificity: pick ONE estate tool that's structurally relevant
                 and reference it with the URL.
    Proof: 3 specific lines from my history that match their need.
    CTA: one clear next step. No "happy to discuss" mush.

  LAYER 4 · SEO (light · just keyword match)
    Use the exact keywords from their job post in the proposal so
    Upwork's search matches.

  LAYER 5 · AI-SEO (citation-shape)
    Bullet structure · table if applicable · attributable claims
    ("60+ live builds at ai-nativesolutions.com").

  LAYER 6 · PLATFORM (Upwork-native)
    Length: 180-280 words max.
    Open with their NAME (extract from "Hi [name]" patterns or
    "[Company Name] is hiring..."). If no name: "Hi —"
    Close with a specific availability ("I can scope this Thursday
    or Friday. 30 min, free, no pitch.").
    Add ONE estate URL inline.

  STRUCTURE (proposal template):
    Hi [name],

    [Jung layer · name what they actually want · 1-2 sentences]

    [Freud layer · puncture the surface ask · 1 sentence]

    [Sales 101 · here's why I match · 3-5 bullets · each one specific]
    · [Specific match #1 from their description]
    · [Specific match #2 from their description]
    · [Reference ONE estate tool with URL]
    · [3rd or 4th if relevant]

    [CTA · concrete next step · time-anchored · no fluff]

    [signature]
    Simon · sjgant80-hub.github.io · ai-nativesolutions.com

  Save each proposal to ./upwork-queue/<jobid>.md with this header:
    # [Job title]
    URL:      [job apply URL]
    Budget:   [budget snippet]
    Client:   [name if extractable]
    Reasoning: [1 line · why this matched]
    Triage score: [1-10]
    Generated: [ISO timestamp]
    ─────
    [proposal body]

STEP 5 · QUEUE REVIEW
  After all jobs drafted:
    1. List the queue: `ls ./upwork-queue/`
    2. Summarise: "{n} drafts ready · highest scores: {top 3 titles}"
    3. ask_user "Open the queue folder to review? [yes/skip]"
    4. On yes: T0 · cli_run "code ./upwork-queue" (or platform
       equivalent to open in editor)
    5. ask_user "Mark drafts to send · either say 'send all' OR
                paste a list of jobids · OR say 'skip'"

STEP 6 · SEND APPROVED
  For each approved jobid:
    6.1 Read ./upwork-queue/<jobid>.md
    6.2 Extract the proposal body (everything after the "─────" line)
    6.3 T0 · cli_run to copy to clipboard:
        Windows: `echo "<body>" | clip`
        Mac:     `pbcopy < <(echo "<body>")`
        Linux:   `xclip -selection clipboard`
        (use shell-safe escaping for the body)
    6.4 T3 · browser_navigate to the job apply URL.
    6.5 browser_screenshot to confirm we're on the proposal page.
    6.6 ask_user "I copied the proposal to your clipboard and opened
                  the apply page. Paste it (Ctrl+V) in the cover
                  letter field, set bid amount, then say 'sent' or
                  'skip' to move to the next one."
    6.7 On "sent": log to ./upwork-queue/SENT.log with timestamp.
        On "skip": log to ./upwork-queue/SKIPPED.log with reason.

STEP 7 · END-OF-RUN SUMMARY
  Print:
    · Jobs found:       N
    · Triaged in:       N
    · Drafts queued:    N
    · Sent:             N
    · Skipped:          N
    · Next run:         (suggest cron · e.g. every 4 hours)
