  For each draft:

    d. browser_key "Tab" through to proposal body field
    e. browser_key "Control+a" · clear any default text

    g. If job requires answers to screening questions:
         browser_screenshot · ← PAUSE: ask_user to answer in chat ·
         si-didy types each answer verbatim from user response
    h. browser_screenshot · final review
    i. ← PAUSE: ask_user "Submit this proposal? [yes/no/edit]"

       · edit → reload .md and re-type
       · no   → skip, leave .md status=skipped
    j. On submit: append to ./upwork-log/YYYY-MM-DD.jsonl
       { ts, job_id, title, template, archetype, connects_used,
         boosted, fallmap_link, result: "sent" }

  Hard stop at 8 sends per day (Pack G discipline).
  If 8 reached: print warning, stop the loop.
